# SM Launcher

Лаунчер для Minecraft: Java Edition. Бэкенд на Python, интерфейс на HTML, CSS и JS в окне [pywebview](https://pywebview.flowrl.com/). Игра скачивается через [minecraft-launcher-lib](https://pypi.org/project/minecraft-launcher-lib/), моды берутся с [Modrinth](https://modrinth.com/).

## Возможности

- Запуск Vanilla, Fabric и Forge, режим оффлайн по нику
- Автоматическая загрузка нужной Java для каждой версии игры
- Зелёная точка у уже установленных версий, кнопка «Загрузить» вместо «Играть» для неустановленных
- Магазин модов: поиск, фильтр по загрузчикам и версиям, выбор версии мода перед установкой
- «Мои моды»: библиотека всего, что скачано в лаунчере
- Свои версии (сборки): у каждой своя изолированная папка с модами и настройками, они появляются в списке на вкладке «Играть»
- Добавление модов в сборку: из библиотеки, из файла или перетаскиванием; архивы `.zip` и `.mrpack` распаковываются, а моды и файлы сборки показываются списком
- Уведомления об установках, настройка памяти для игры
- Обновление через GitHub Releases

## Запуск из исходников

Нужен Python 3.9 или новее. На Windows также нужен WebView2 Runtime (в Windows 10 и 11 уже есть).

```
pip install -r requirements.txt
python launcher.py
```

## Сборка установщика (Windows)

Нужны [Inno Setup 6](https://jrsoftware.org/isinfo.php) и Python.

```
build.bat
```

Скрипт берёт версию из `version.py`, собирает папку `dist\SM Launcher` через PyInstaller (`--onedir`) и делает установщик `installer\SMLauncher-Setup-<версия>.exe`.

Основная команда сборки:

```
pyinstaller --noconfirm --onedir --windowed --name "SM Launcher" --add-data "ui;ui" --collect-all webview --collect-all minecraft_launcher_lib launcher.py
```

Установщик ставится в папку пользователя и не требует прав администратора. Он не подписан, поэтому Windows SmartScreen может показать предупреждение.

## Обновления через GitHub

1. Поменяй версию в `version.py` и собери установщик.
2. Создай релиз на GitHub с тегом вида `v1.0.1`.
3. Прикрепи к релизу файл `SMLauncher-Setup-1.0.1.exe`.
4. В лаунчере открой настройки (шестерёнка в верхней панели) и впиши репозиторий в формате `имя/репозиторий`. Можно также указать его в `GITHUB_REPO` в `launcher.py`.

При запуске лаунчер проверяет последний релиз, и при наличии новой версии приходит уведомление. Кнопка «Обновить» скачивает установщик, тихо запускает его и перезапускает лаунчер. При запуске из исходников кнопка просто открывает страницу релиза.

## Где хранятся данные

Всё лежит в папке `.mylauncher` в домашней папке пользователя (например, `C:\Users\<имя>\.mylauncher`):

| Путь | Что там |
|---|---|
| `minecraft/` | версии, библиотеки, ассеты и Java |
| `library/` | «Мои моды», всё скачанное из магазина |
| `instances/<название>/` | своя версия: папка `mods`, конфиги и остальные файлы игры |
| `settings.json` | ник, загрузчик, версия, память, репозиторий, уведомления |

## Структура проекта

```
launcher.py        бэкенд и локальный сервер
version.py         номер версии
ui/index.html      интерфейс
requirements.txt   зависимости
build.bat          сборка
installer.iss      скрипт Inno Setup
```

## Ограничения

- Только оффлайн-режим, входа через аккаунт Microsoft нет.
- Архивы RAR и 7z не распаковываются. Из модпаков CurseForge берутся только файлы внутри архива, сами моды по списку не скачиваются.
- OptiFine автоматически не скачивается: его нужно взять с optifine.net и добавить как обычный `.jar`.
- Моды из магазина попадают в «Мои моды», а в игру они попадают после добавления в свою версию.
