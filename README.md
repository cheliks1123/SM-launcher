# SM Launcher

Лёгкий лаунчер для Minecraft: Java Edition со встроенным магазином модов и своими сборками. Установил, выбрал версию, играешь.

**Статус: ранняя бета.** Основное уже работает, проект активно развивается.

## Почему SM Launcher

- **Всё в одном окне.** Версии, моды и сборки больше не нужно искать по папкам и сайтам.
- **Ничего не надо настраивать.** Нужная Java для каждой версии игры скачивается сама.
- **Магазин модов внутри.** Поиск, фильтр по загрузчику и версии игры, выбор версии мода и установка в один клик.
- **Свои сборки.** Каждая сборка изолирована: у неё свои моды и настройки, и они не мешают другим версиям. Перетащи модпак в окно, и он распакуется сам, а ты увидишь все моды и файлы внутри.
- **Сразу видно, что установлено.** У установленных версий горит зелёная точка. Для неустановленных кнопка «Играть» сама превращается в «Загрузить».
- **Помнит тебя.** Ник, версия, загрузчик и объём памяти сохраняются между запусками.
- **Уведомления.** Колокольчик в верхней панели показывает, что было установлено и добавлено.
- **Обновления прямо в лаунчере.** Вышла новая версия, нажал «Обновить», и всё готово.

## Интерфейс

Тёмный, минималистичный, с плавными анимациями. Внизу четыре вкладки:

- **Играть.** Ник, загрузчик, версия и одна большая кнопка. Здесь же доступны твои собственные версии.
- **Версии.** Твои сборки карточками. Создание в два шага, на странице сборки список модов, список всех файлов и перетаскивание файлов.
- **Магазин.** Таблица модов с иконками, описаниями и числом загрузок, поиск и фильтры.
- **Мои моды.** Всё, что ты скачал. Моды можно удалять и добавлять в сборки.

Сверху шапка: уведомления, быстрая кнопка папки с модами и настройки (память для игры и обновления).

## На каком этапе проект

**Уже есть**

- Запуск Vanilla, Fabric и Forge
- Автоматическая Java
- Магазин модов, свои сборки, импорт `.zip` и `.mrpack`
- Сохранение настроек, уведомления, обновления
- Установщик для Windows

**В планах**

- Вход через аккаунт Microsoft
- Поддержка NeoForge
- Автоматическая установка зависимостей модов
- Распаковка архивов RAR и 7z
- Поддержка модпаков CurseForge

**Пока ограничения**

- Только режим оффлайн
- Только Windows 10 и 11
- OptiFine автоматически не ставится, его `.jar` можно добавить в сборку вручную

## Установка

Скачай `SMLauncher-Setup-<версия>.exe` в разделе **Releases**, запусти и следуй установщику. Windows может показать предупреждение SmartScreen, потому что установщик пока не подписан.
